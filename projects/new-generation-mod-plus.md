## Overview

**New Generation Mod Plus** is a Return to Castle Wolfenstein modification I created with **MrPingu** in 2007–2008.

It was one of the first mods available on RtCW **DEMO** and later RtCW **1.0**. It was also my first experience programming in C, after having scripted in Perl and PHP.

## Features

New Generation Mod Plus was the second iteration of the original New Generation Mod. It was significantly more stable with bug/crash fixes and contained a polished admin system.

Key features included:

- 🛠 **Admin system** — comprehensive server management tools
- 🏆 **Tournament support** — match-ready configuration
- 🌐 **"Delagged System"** — a shot prediction system implemented from a [Code3Arena](https://web.archive.org/web/20080802054042/http://code3arena.planetquake.gamespy.com/tutorials) article

## Learning Through Modding

Back then, [Code3Arena](https://web.archive.org/web/20080802054042/http://code3arena.planetquake.gamespy.com/tutorials) contained a wealth of modding tutorials for Quake3. It's thanks to Code3Arena and modding that I learned most of my C programming.

Although the tutorials were specifically made for Quake3 Arena (Q3A), we could apply many of them to the RtCW codebase because RtCW's engine was based on the Quake3 Arena's **id Tech 3** engine.
